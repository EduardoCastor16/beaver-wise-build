# Beaver Build Bureau

Esses arquivos que eu estou te mandando são referências pra você se basear e construir algo. Lembrando que eu quero uma visão final muito profissional. A minha marca deve transmitir leveza, mas ao mesmo tempo mostrar que vai ser construído algo com inteligência, com estratégia, assim como os castores são na prática. Não quero que você invente imagens, ééé, nem logos. Vou te enviar arquivo com essas logos, monograma simplificado. Vou te enviar o arquivo que contém e você deve extrair e usar a partir deles
